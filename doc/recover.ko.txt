RECOVER(6)                       게임 매뉴얼                       RECOVER(6)

이름
       recover - 재해로 인해 중단된 NetHack 게임을 복구합니다.

개요
       recover [ -d 디렉토리 ] base1 base2 ...

설명
       때때로 NetHack 게임은 게임 자체나 시스템 충돌로 인해 비정상 종료될 수
       있습니다. NetHack v3.1 이전에는 플레이어 인벤토리 같은 정보가 메모리에만
       있었기 때문에 이런 게임을 복구할 수 없었습니다. 이제는 관련 정보를 디스크에
       기록하므로 마지막 레벨 변경 시점부터 게임을 복구할 수 있습니다.

       기본 옵션은 처리할 파일을 복구하도록 지시합니다. 각 기본 옵션은 별도의 게임 복구를 지정합니다.

       -d 옵션은 나타나는 경우 첫 번째 인수여야 하며 NetHack 놀이터인 디렉터리를 제공합니다. 이는 NETHACKDIR,
       HACKDIR 또는 컴파일 중에 게임 관리자가 지정한 디렉터리(일반적으로 /usr/games/lib/nethackdir)의 값을
       재정의합니다. NetHack은 일반적으로 플레이어가 레벨을 떠날 때 레벨에 대한 파일을 작성하므로 다시 방문할 준비가 됩니다.
       체크포인트할 때 NetHack은 입력된 레벨과 모든 레벨 변경 시 현재 게임 상태도 기록합니다. 이로 인해 자연스럽게 레벨
       변화가 다소 느려집니다.

       레벨 파일 이름은 base.nn 형식입니다. 여기서 nn은 해당 레벨의 내부 장부 번호입니다. 파일 base.0은 게임 식별,
       잠금 및 체크포인트 시 게임 상태에 사용됩니다. 다양한 OS는 기본 이름을 구성하기 위해 다양한 전략을 사용합니다.
       마이크로컴퓨터는 해당 시스템에서 합법적인 파일 이름이 되도록 잘리고 수정된 문자 이름을 사용합니다. 다중 사용자 시스템은 충돌을
       피하기 위해 사용자 번호가 앞에 붙은 (수정된) 캐릭터 이름을 사용하거나 동시 플레이어 수가 제한되는 경우 "xlock"을
       사용합니다. 중단된 게임의 올바른 기본 이름을 찾으려면 플레이그라운드를 살펴봐야 할 수도 있습니다. 복구는 이러한 레벨 파일을
       nethack이 사용한 것과 동일한 이름의 저장 파일로 변환합니다.

       복구는 플레이그라운드에서 파일을 읽고 삭제할 수 있어야 하며 저장 디렉터리에 파일을 생성할 수 있어야 하기 때문에 게임 보안과
       흥미로운 상호 작용을 합니다. 일반 플레이어에게 setuid 또는 setgid를 통해 복구할 수 있는 액세스 권한을 부여하는
       것은 다른 플레이어를 속이고 엉망으로 만드는 측면에서 플레이그라운드를 세계 쓰기 가능 상태로 두는 것과 같습니다. 단일 사용자
       시스템의 경우 이는 물론 아무것도 변경되지 않으므로 기본적으로 설치된 마이크로컴퓨터 포트 중 일부가 복구됩니다.

       다중 사용자 시스템의 경우 게임 관리자는 호스트 시스템이 부팅될 때 복구되도록 플레이그라운드에 있는 모든 .0 파일을 준비하고
       게임 충돌을 개별적으로 처리할 수 있습니다. 사용자 집단을 충분히 신뢰할 수 있는 경우 nethack 실행 파일과 동일한
       권한으로 복구를 설치할 수 있습니다. 두 경우 모두 복구는 배포 유틸리티 디렉터리에서 쉽게 컴파일됩니다.

참고
       nethack 자체와 마찬가지로 recover는 같은 이름의 기존 저장 파일을
       덮어씁니다. recover가 생성한 저장 파일은 압축되지 않으며, 원하면 나중에
       압축할 수 있습니다. 다만 압축 기능을 사용하는 nethack이라도 압축되지 않은
       저장 파일을 읽을 수 있습니다.

또한 참조
       nethack(6)

버그
       recover는 주어진 기본 이름이 실제 진행 중인 게임인지 판별하지 않습니다.
       여러 시스템이 같은 플레이그라운드를 공유하는 경우 이 문제를 자동으로
       구분하기는 사실상 불가능합니다.

       recover도 충돌 방지를 위해 nethack의 플레이그라운드 잠금 메커니즘을
       사용하도록 개선되어야 합니다.
