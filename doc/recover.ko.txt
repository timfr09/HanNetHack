복구(6) 게임 매뉴얼 복구(6)



이름
       복구 - 재해로 인해 중단된 NetHack 게임을 복구합니다.

개요
       [ -d 디렉토리 ] base1 base2 복구 ...

설명
       때때로 NetHack 게임은 다음과 같은 경우 재난으로 인해 중단될 수 있습니다.
       게임이 중단되거나 시스템이 충돌합니다.  NetHack v3.1 이전에는 이러한 게임이
       플레이어의 인벤토리 등 다양한 정보가 보관되어 손실됨
       기억 속에만.  이제 모든 관련 정보를 다음 위치에 기록할 수 있습니다.
       디스크이므로 해당 게임은 마지막 레벨 지점에서 복구할 수 있습니다.
       변화.

       기본 옵션은 처리할 파일을 복구하도록 지시합니다.  각 기본 옵션
       별도의 게임 복구를 지정합니다.

       -d 옵션이 나타나면 첫 번째 인수여야 하며 다음을 제공합니다.
       NetHack 놀이터인 디렉토리입니다.  값을 무시합니다.
       NETHACKDIR, HACKDIR 또는 게임 관리자가 지정한 디렉터리에서
       컴파일 중 istrator(보통 /usr/games/lib/nethackdir).
       NetHack은 일반적으로 플레이어가 레벨을 떠날 때 레벨에 대한 파일을 작성합니다.
       그러면 그들은 재방문을 할 준비가 될 것입니다.  체크포인트할 때 NetHack
       또한 매 순간마다 입력된 레벨과 현재 게임 상태를 기록합니다.
       레벨 변화.  이로 인해 자연스럽게 레벨 변화가 다소 느려집니다.

       레벨 파일 이름은 base.nn 형식입니다. 여기서 nn은 내부 이름입니다.
       해당 레벨의 장부 번호입니다.  파일 base.0은 게임에 사용됩니다.
       신원, 잠금 및 체크포인트 시 게임 상태에 대한 정보입니다.   다양한-
       다양한 OS는 기본 이름을 구성하기 위해 다양한 전략을 사용합니다.
       마이크로컴퓨터는 잘리고 수정된 문자 이름을 사용합니다.
       해당 시스템에서 유효한 파일 이름이어야 합니다.  다중 사용자 시스템은 다음을 사용합니다.
       (수정) 충돌을 피하기 위해 캐릭터 이름 앞에 사용자 번호가 붙습니다.
       또는 동시 플레이어 수가 제한되는 경우 "xlock"입니다.  그것
       올바른 베이스를 찾으려면 놀이터를 살펴봐야 할 수도 있습니다.
       중단된 게임의 이름.  복구는 이러한 수준의 파일을 변환합니다
       nethack이 사용한 것과 같은 이름의 저장 파일에 저장됩니다.

       복구는 플레이그라운드에서 파일을 읽고 삭제할 수 있어야 하기 때문에
       저장 디렉터리에 파일을 생성하면 흥미로운 상호 작용이 가능합니다.
       게임 보안으로.  일반 플레이어에게 다음을 통해 복구할 수 있는 액세스 권한을 부여합니다.
       setuid 또는 setgid는 놀이터 세계를 떠나는 것과 같습니다.
       다른 플레이어를 속이고 엉망으로 만드는 것과 관련하여 쓰기 가능합니다.
       단일 사용자 시스템의 경우 이는 물론 아무 것도 변경되지 않으므로
       일부 마이크로컴퓨터 포트는 기본적으로 복구를 설치합니다.

       다중 사용자 시스템의 경우 게임 관리자가 다음 사항을 준비할 수 있습니다.
       호스트가 복구할 때 놀이터에 있는 모든 .0 파일을 공급해야 합니다.
       머신을 부팅하고 게임 충돌을 개별적으로 처리합니다.  사용자가 대중적인 경우
       신뢰할 수 있는 경우 복구를 다음과 함께 설치할 수 있습니다.
       nethack 실행 파일과 동일한 권한이 있습니다.  두 경우 모두 복구
       배포 유틸리티 디렉토리에서 쉽게 컴파일됩니다.

참고 사항
       nethack 자체와 마찬가지로 복구는 기존 저장 파일을 덮어씁니다.
       같은 이름.  복구로 생성된 저장 파일은 압축되지 않습니다. 그들은 아마도
       원하는 경우 나중에 압축하지만 압축을 사용하는 nethack도 가능합니다.
       압축되지 않은 형태로 찾을 수 있습니다.

버그
       복구는 기본 이름이 게임을 지정하는지 확인하려고 시도하지 않습니다.
       진전.   여러 기계가 플레이그라운드를 공유하는 경우 이는 다음과 같습니다.
       결정하는 것은 불가능합니다.

       Recover는 nethack 놀이터 잠금 장치를 사용하는 방법을 가르쳐야 합니다.
       갈등을 피하기 위한 주의.
